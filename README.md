# Проекты 📋
## Проект 1: Тестирование личного кабинета для учителей Skyeng 

▶️**Описание:**

Проводилось тестирование нового функционала для преподавателей платформы Skyeng — модуля «Личные события». Этот инструмент позволяет учителям добавлять в свое расписание персональные встречи и задачи, не привязанные к конкретным ученикам школы.

▶️**Цель проекта:**
Комплексная проверка новой фичи для принятия решения о готовности продукта к релизу.

[Ссылка на проект](https://github.com/skripnikovaleksej44-ui/osnovi_testirovaniya_LK)

▶️**Выполненные работы:**
1. Проведен детальный анализ требований к новому функционалу.
2. Разработан комплект тестовой документации: чек-листы и тест-кейсы.
3. Выполнены следующие виды тестирования:
   * **Смоук-тестирование** (Smoke testing);
   * **Функциональное тестирование** основных сценариев;
   * **Регрессионное тестирование** после исправления дефектов;
   * **Приемочное тестирование** (UAT).
4. Зафиксированы найденные дефекты (оформлены баг-репорты).
5. Подготовлен финальный отчет о результатах тестирования с рекомендациями по релизу.

▶️**Какие инструменты были применены:**

- Miro для создания декомпозиции новой функциональности
- TestIT для подготовки тест-кейсов и чек-листов
- Yonote для ведения тест-плана и отчета
- Ёжка для фиксирования найденных дефектов

## Проект 2: Тестирование API личного кабинета для учителей в вэб-приложении от Skyeng

▶️**Описание:**

Проведено комплексное тестирование бэкенда для нового функционала «Личные события» в расписании преподавателей платформы Skyeng. Основная задача заключалась в проверке бизнес-логики интеграции личных мероприятий и подтверждении корректности обработки запросов сервером. Для тестирования была составлена коллекция запросов в Postman. По завершении тестирования был доработан отчет к первому проекту [«Основы тестирования»](https://github.com/skripnikovaleksej44-ui/osnovi_testirovaniya_LK).

▶️**Цель проекта:** Проведение позитивного и негативного функционального тестирования API на основе разработанных тест-кейсов для проверки стабильности бэкенд-части приложения.

[_**Ссылка на проект**_](https://github.com/Veron242/testirovaniyeAPI)

▶️**Какие инструменты были применены:**

* Swagger для чтения документации API на проекте
* DevTools для воспроизведения запросов в рабочей среде
* Postman для создания коллекции и автоматизации тестирования
* Confluence для ведения тест-плана и отчета
* Jira для фиксирования найденных дефектов
